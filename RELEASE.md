# Constructions materials v2026.10.1

Reader materials for **Constructions. The Craft of Formalization**, English
edition 2026.10 (book published 14 October 2026).

- Read the book: https://books.arxo.io/constructions/
- Browse and clone the models: https://github.com/arxohq/constructions
- Install from an ordinary clone with `npm ci`, then run `npm test`.
- CLI is pinned to `@arxo/cli@0.2.4`. The companion contains no executable.

The repository preserves the published curated companion byte for byte.
CI verifies its manifest and runs the 383 selected scenarios in 119 test
files, Water answer/proof replay, all four support states and expense evidence.
The original acceptance of all 50 printed command blocks is retained as
historical evidence; CI does not repeat those interactive study sessions.

Attached PDF, EPUB and companion ZIP are the original book-site downloads.
Check them with `sha256sum -c SHA256SUMS` (or `shasum -a 256 -c SHA256SUMS`).
