# Constructions: independent reader pilot

English edition 2026.10, 14 October 2026 · Optional reader feedback

Read the prologue and chapters 1–4 in order. No prior experience with Arxo
is expected. Use the book without the tutorial track and without help from
its author. This first session tests understanding by reading; command
execution is a separate session. Its automated route is ready in the npm
reader companion. The AI editorial review with Codex and Astra is complete;
a human session has not been performed. This protocol collects optional feedback. Use
reader-feedback.en.md to record the session and preserve the file fingerprints.

Record your own answers before checking the book again. Please include the
chapter, heading or page at each point where you needed an explanation.

1. A vocabulary declares `donates_proton`. Does that tell us that water
   donates a proton? What additional entry would be needed?
2. The case records information about water, but the question is about
   ammonia. What is the answer, and does it mean the claim is false?
3. Which error can a type check catch? Which kind of mistake about the
   world would remain undetected by such a check?
4. Explain the amphiproticity rule in one sentence. Then remove the
   assertion about accepting a proton: what follows, and why?
5. How does an assertion against a claim differ from no assertion at all?
   How do `assert not` and `refuted` differ in the displayed examples?
6. There is support both for and against proton donation. Does changing
   the order of the entries change the state of support?
7. Donation is established, but acceptance is both supported and opposed.
   What happens to the amphiproticity conclusion, and why?
8. Add an assertion about water's conjugate acid. Does it change the
   displayed conclusion or its grounds?
9. What missing premise does the explanation name when only donation
   is recorded? What changes if the second assertion refers to a misspelled
   object identifier?
10. Explain one complete displayed rule and one explanation in your own
    words. Could you do so without looking ahead to a later chapter?

After the questions, read the transition to chapter 5. Explain what skill
you already know and what new problem the triangle example introduces.

## Practical session with the public-runtime companion

Use the release's verified installation instructions in a clean directory.
Open the Water companion, run its saved question, then copy the package to
another directory and repeat it. Compare the results and their fingerprints.
Make the one bounded change described in chapter 18 and explain the new
answer before reading the result. Record the operating system, exact tool
version, commands, outputs and any required help. A successful reading
session alone does not establish a successful practical session.
