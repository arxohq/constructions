# Mutation notes

The book runs `law engine mutate` on a selected CLIR program.
A valid mutation changes a local program component; a checked scenario
may distinguish it by failing its recorded expectation. Chapter 17
shows the distinction between testing one mutation and establishing
the completeness of the model. The selected chemical suite has
22 scenarios. Product implementation source is not part of this book
distribution. See reader-commands.json for the printed route.
