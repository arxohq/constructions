# Adaptations for npm CLI 0.2.4

Pinned historical inputs are retained by the publisher. The distribution
contains separately prepared sources and IR/0.7 with current locks 0.4.
The temporary build workspace and private historical archive are excluded.
No equivalence to the retired semantic version is claimed.

- Explicit local imports and dependency manifests were generated by the CLI.
- The evidence-policy profile became law.core.evidence-policy/0.2.
- Test headers, one named Scrum deadline policy and an IETF position name
  were migrated. The documented four independent Hilbert incidence-query
  status expectations remain COMPUTED.
- Seven SI rule calls `with_unit(1, ...)` and their explanatory comment use
  `with_unit(scalar_of(magnitude(1 m) / magnitude(1 m)), ...)` instead.
  This exact dimensionless unity returns Rational, which the published
  `with_unit` accepts. The literal 1 lowers to Number, which this CLI refuses.
  No SI test expectations or comparison operators were changed. The earlier
  20 TYPE_ERROR failures remain in the publisher's dated migration report;
  the corrected layer passes all 383 selected scenarios.
- Syzdyq's source edition is ABSTRACT_ONLY. The full local handbook and two
  long fragment quotations are removed from this distribution. Bibliographic
  data and the original publication digest remain; rules and expectations
  are unchanged. Source-text coverage is not claimed for this edition.
- Chapter 18 uses prepared packages, native install/ask/eval/inspect calls,
  and current dependency source snapshots and artifact hashes.

Per-file before/after digests and transformation notes are in execution.json.
